 Fashion Trend Creation System

## 📌 Project Description

Fashion Trend Creation System is a web-based application developed
to provide fashion trend recommendations based on user-selected
preferences.

The system uses a rule-based recommendation method to suggest
suitable fashion trends based on gender, season, category, colour,
and style.

## 🎯 Objectives

- To provide suitable fashion trend recommendations.
- To allow users to register and login.
- To collect fashion preferences from users.
- To provide trend-based recommendations.
- To collect user feedback.
- To allow the admin to manage users, trends, and feedback.

## 🛠️ Technologies Used

- Frontend: HTML, CSS, JavaScript
- Backend: Python Flask
- Database: SQLite
- Development Tool: Visual Studio Code
- Platform: Web Application

## ⚙️ Recommendation Method

The system uses a rule-based method.

User selects:

- Gender
- Season
- Category
- Colour
- Style

Based on these selections, the system provides a suitable fashion
trend recommendation.

## 🗄️ Database

SQLite is used as the backend database.

Database file:

fashion_trend.db

The database stores:

- User details
- Fashion trend details
- Feedback details
